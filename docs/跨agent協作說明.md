# 我的跨 Agent 交班與派工流程（簡易說明）

> 讓 Claude Code、Codex、Gemini（Antigravity）三個 AI 在同一個專案上輪班接力、
> 還能讓聰明的 AI 當「軍師」把粗工派給便宜的 AI 做——省下大量昂貴 token。

## 一、核心概念：接力賽 + 包工頭

- **交班（接力賽）**：不同 AI（或同一個 AI 的不同對話）輪流接手同一個專案。
  換人時不用從頭解釋，說一聲「開工」就知道上次做到哪。
- **派工（包工頭）**：聰明貴的 AI（Claude）負責規劃和驗收，
  把大量重複的粗工（寫網頁、產講義）派給另一池額度的 AI（Codex / Gemini CLI）做。

## 二、交班：三層檔案 + 一根接力棒

| 層 | 檔案 | 角色 | 比喻 |
|---|---|---|---|
| 規則 | repo 的 `AGENTS.md` | 固定規矩，所有 AI 都讀 | 班規 |
| 短期 | repo 的 `HANDOFF.md`（≤20 行） | 每次收工覆寫的現況快照 | 桌上便條紙 |
| 長期 | Obsidian `工作筆記.md` + `工作筆記-log.md` | 深度脈絡與交班史（只增不刪） | 日誌本 |

**接力棒 = `handoff_id`**：每次收工產生一組編號，同時寫進 HANDOFF.md、筆記、log 三處。
下一棒開工時比對三處編號——一致就接手；不一致代表有人同時寫入或上次沒收好工，
AI 會**停下來問人**，絕不猜。

**日常只要兩個口令**：
- 「**開工**」→ AI 讀便條紙 + 對接力棒編號，回報上次進度和建議下一步
- 「**收工**」→ AI 更新筆記、蓋新接力棒、覆寫便條紙（commit/push 要我點頭才做）

**省 token 的關鍵**：開工只讀便條紙和筆記開頭幾行（幾百 token），
不把越長越肥的筆記全文塞進 AI 腦袋；收工只改動的段落、不整本重抄。

## 三、派工：計畫書進、成果單出

角色分工：
- **軍師**（Claude Code，開著的視窗）：寫計畫書、派工、驗收、記帳
- **士兵**（背景 CLI，看不見畫面）：照計畫書出工
  - Codex：`/Applications/ChatGPT.app/Contents/Resources/codex exec "..."`
  - Gemini：`agy -p "..."`（Antigravity CLI，brew 可裝，共用桌面版登入）

流程五步：

```
1 規劃   軍師寫 tasks/<任務>/TASK.md（輸入、預期產出、限制、權限，缺一不可）
2 派工   背景呼叫士兵 CLI；平行任務各開一個資料夾，互不干擾
3 出工   士兵產出檔案 + 寫一張 ≤20 行的 result.md 成果單
4 驗收   軍師只讀成果單 + git diff + 跑測試（不讀士兵的對話全文！）
         要改就寫 FIXES.md 派回去，不自己動手重寫
5 記帳   全部驗收完才更新交班檔案
```

**鐵律**：士兵只能寫自己的任務資料夾，不准碰交班檔案、不准 commit——
不然多個 AI 同時寫共享狀態，資料一定打架。

## 四、為什麼省錢

- AI 最燒 token 的是「寫東西」，讀便宜得多 → 寫程式給便宜 AI，聰明 AI 只讀 diff 驗收
- 計畫書寫得好，笨一點的 AI 也能做得好 → 貴的腦力花在計畫書上最划算
- 士兵的對話過程全部落地成檔案，絕不灌回軍師的上下文

## 五、想自己搭？最小起步

1. 選一個「軍師」AI（建議 Claude Code），幫它寫好開工/收工兩個技能（skill）
2. 專案裡放 `AGENTS.md`（規矩）和 `HANDOFF.md`（便條紙），筆記放 Obsidian
3. 裝士兵 CLI：ChatGPT.app 內建 codex、`brew install --cask antigravity-cli`
4. 把這份說明丟給你的 AI，說「照這個幫我搭一套」——它會懂 😄
